# Tracking Intensity over Time

Simple workflow to track the intensity at 800 nm across OA frames, showing the signal in the radial artery. First by using the mean intensity in the ROI as target feature, then by counting the number of pixels above a given threshold to identify signal pulses.

**Target user:** A researcher interested in how OA intensities change over time, for example to track blood flow changes, pulse, exercise effects etc.
